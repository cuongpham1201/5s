5S Daily — prototype assets

This folder is reserved for static assets (logos, sample photos, icons).
The HTML/CSS prototype uses pure-CSS placeholders (gradients + emoji + inline SVG)
instead of binary images, so no real files are required to review the UX.

Drop real assets here when moving to the Next.js build:
  - logo.svg
  - sample-5s-1.jpg ... (gallery / preview samples)
  - icon-192.png / icon-512.png (PWA manifest)
